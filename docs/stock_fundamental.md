# Stock Fundamental Module

Fundamental data for A-share, HK, and US stocks: financial statements, IPO data, profit forecasts, share capital structure.

## Sub-modules

- **eastmoney** — Financial statements from Eastmoney (balance sheet, profit, cash flow, indicators)
- **sina** — Financial analysis from Sina
- **ths** — Financial data from THS (同花顺)

## Key Functions

- Financial analysis indicators
- HK/US financial reports
- IPO registration, restricted releases
- IPO declare/review/tutor
- Profit forecasts
- Share capital structure
- Main business composition
- Stock notices
